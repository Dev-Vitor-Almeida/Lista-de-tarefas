# 📋 Lista de Tarefas

Projeto desenvolvido para criar uma lista de tarefas com diferentes níveis de prioridade e gerenciamento de atividades.

## ⚙️ Funcionalidades
- Adicionar tarefas
- Remover tarefas
- Editar tarefas
- Marcar e desmarcar tarefas como concluídas
- Filtrar tarefas por status
- Definir prioridade: alta, média ou baixa
- Contador de tarefas concluídas e pendentes
- Persistência dos dados utilizando `localStorage`
- Validação de tarefas duplicadas
- Atalhos de teclado para edição
- Cancelamento da edição
- Limpeza de tarefas concluídas
- Limpeza de todas as tarefas

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📚 Conceitos praticados

Durante o desenvolvimento, foram praticados conceitos como:

- Manipulação do DOM
- Eventos com `addEventListener`
- Eventos de teclado
- Criação e manipulação de elementos com JavaScript
- Arrays e objetos
- Funções
- Condicionais
- Métodos como `forEach()`, `findIndex()`, `some()` e `filter()`
- `JSON.stringify()` e `JSON.parse()`
- `localStorage`
- Manipulação de propriedades e estilos dos elementos
- Validação de dados
- Manipulação de classes com `classList`
- Responsividade com CSS
